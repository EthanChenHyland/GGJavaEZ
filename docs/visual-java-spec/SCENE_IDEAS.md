# Scene Ideas

## Stack Cathedral

Method frames appear as nested architectural planes or chambers connected by a clear execution axis. The active frame sits closest to the user or at the brightest focal depth. Parent frames remain visible enough to communicate context.

## Heap Constellation

Objects occupy a separate spatial field. Strongly connected structures can cluster. Selected references reveal routes between stack and heap. Large object graphs can progressively simplify until the user focuses them.

## Recursion Shaft

Recursive frames descend along a controlled spatial axis, giving call depth an immediately visible physical meaning. Return propagation travels back upward with values.

## Array Rail

Arrays become aligned physical slots. Indices remain stable. Algorithms can temporarily expand into a dedicated visualization theater without breaking runtime identity or timeline synchronization.

## Tree Observatory

Tree nodes occupy hierarchical 3D space. Traversal can move a focus beam through nodes while the timeline shows recursive or iterative call state.

## Exception State

When an exception occurs, ordinary ambient motion stops. Unrelated structures dim. The causality chain is isolated from the throw site through active frames. The user can click any propagation step to jump to that exact execution state.

## Object Life Mode

Selecting an object and choosing “Follow life” reorients the timeline around that object's history: allocation, field mutations, inbound/outbound reference changes, method interactions, and last reachable state.
