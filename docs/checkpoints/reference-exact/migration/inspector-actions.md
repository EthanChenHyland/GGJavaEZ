# Inspector actions and captured Source preview — 2026-10-19

Requirement 28.6 now has three contextual header actions: Focus (Return to World while Focus is active), Reveal Source and Copy Value. Focus/Return use the existing camera behavior and command availability. Reveal/Copy are registered View commands; the Inspector and Command Palette execute the same mounted World provider, rechecking current availability before side effects. Disabled actions remain keyboard reachable and expose their registry reason. Missing items cannot copy a placeholder, borrow an unrelated entity with the same opaque ID or reveal a future source event.

The action target resolves only applied-prefix evidence. A frame uses its captured source, an object its allocation site, a row its verified current evidence, a reference its recorded binding evidence, and a retired local its captured declaration. Unknown associations, files and out-of-range lines disable Reveal Source. Historical bindings use their verified introduction event rather than a current owner's unrelated source. Copy Value uses the same full header formatter as the card, except selected array cells copy their exact captured value. Sparse unavailable cells retain the explicit unavailable status; incomplete copied values declare their observation status. Clipboard rejection produces a truthful status message. Copy completion cannot display a stale message for a different item/prefix.

An explicit Reveal Source creates one transient receipt bound to recording, prefix, target and a monotonically increasing request revision. It displays the immutable captured source file in the existing read-only editor. It opens Source and closes the covering Inspector while preserving selection, Focus, camera, AppState, anchors, executing-source binding and editable drafts. A distinct reveal arrow/highlight does not claim the associated allocation/declaration line is currently executing. Reissuing Reveal after manual scrolling reveals again. Cursor, recording, selection or workspace-file changes invalidate the preview. Closing it restores the underlying editor and releases its temporary Monaco model; repeated reveals do not accumulate models. It does not guess a workspace path or reuse the executing-source mutation handler.
