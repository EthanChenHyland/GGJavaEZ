# Current-reference aggregation

The presentation cut remains the authority for represented entities and exact
cluster membership. `buildReferenceTopology` partitions only the current
`SceneModel.references`; it does not query future or overwritten bindings,
change runtime identities, expand clusters or move canonical anchors.

Every current reference belongs to exactly one category: a drawable individual,
a drawable directed bundle constituent, an unavailable reference with a factual
geometry reason, a relationship inside one collapsed cluster, or an exclusion
by Trace Current scope. The accounting equations are:

```
current = drawable + unavailable + internal + scopeExcluded
drawable = individual + bundled
```

Individual connectors require an actual visible source row/collection key or
value port/current array-cell mapping. Quiet and hidden rows cannot silently
use a body port. Array destinations use the rendered title plate rather than
the reserved envelope. Destinations attach to the nearest actual cuboid face
centre with a small outward offset. Existing connector routing remains shared.

Selected/current-evidence individual connectors are mandatory. Optional
selection/Focus/current-entity context then newest evidence and canonical IDs
fill the nominal connector capacity. Effective capacity is `max(B, M)`; only
drawable mandatory individuals contribute to that overflow. References with a
collapsed endpoint aggregate structurally, regardless of individual priority.

The planner subtracts emitted individuals before grouping the residual by its
directed pair of presented entity or cluster IDs. Structural bundle IDs encode
recording and pair, independently of Cursor/revision/count. Opposite directions
remain distinct. Aggregate endpoints attach to actual represented cuboid faces,
and never claim to be individual storage ports. Bundle curves are not silently
truncated to the individual budget. Their actual count is exposed separately
for performance measurement.

`Selection.kind = 'bundle'` is explicitly structural and cannot Focus a runtime
entity or masquerade as a graph flow. Connector bundles carry required current
reference IDs; flow bundles have no reference-ID payload. Both share the
production ConnectorBatch and semantic emphasis/material tokens. Current
individual connectors now use their actual frame/object/class colour role, with
recorded exception/return precedence. A heterogeneous structural bundle uses
the shared reference colour. Focus and forensic caps compose with relevance.

Native curve selection opens the exact current constituent list in the existing
virtualized Inspector. Selecting a constituent inspects the original reference,
without a camera command. The Inspector reports unavailable reasons and
separate global current-reference counts. Bundle captions use the shared
structural-label placement and font sizing, remain depth-tested world text and
identify references separately from flows. Optional captions may be culled when
the Safe Frame and body/label occlusions leave no readable placement; the real
curve and Inspector remain available.

The helper tests include typed geometry, collection key/value and mapped-array
ports, mandatory overflow, deterministic grouping, unavailable/internal/scope
partitions, 100 randomized cuts and normalized replacement/null/rewind prefixes.
Those fixtures are unit evidence, not actual-JVM acceptance. Desktop and narrow
dense-JVM tests exercise native picking, bounded Inspector DOM, constituent
inspection, replay and Trace Current/All via the production controls.

Historical binding rendering in Trace All, full hierarchy/collection layout,
complete visual approval and sustained performance validation remain open.
