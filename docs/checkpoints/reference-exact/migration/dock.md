# Dock drawers and workspace status — 2026-10-20

The Dock strip, floating drawer and status popover have separate geometry. `computeShellLayout` remains the sole rectangle owner; the strip binds its existing dockStrip rectangle and 24 px hit areas extend above shorter bands. The drawer overlays the unchanged full-viewport canvas, ends at the Time_Dock top and uses the frozen 0.30 H default and 0.20–0.45 H bounds. Its pointer-captured top edge and keyboard separator update the existing session height. Opening Debug/Errors or ingesting an exception no longer overwrites the chosen height. Console, Problems, Debug and Errors are always present in that order; choosing the current open tool closes it, and choosing another leaves only that drawer open.

## Content and command ownership

`ConsoleDrawer` preserves the canonical Console JSX byte for byte, including BoundConsoleOutput session/recording binding, archives, submissions, input focus/acknowledgements and the raw JVM stack. The output group builders move verbatim into useConsolePresentation. No newline, channel, input, ordering, retention or timeline policy changes. The Console count is the logical output-row total across every available group, including the retained process-output disclosure; recorder and supplementary pipe rows stay explicitly separate. Input acknowledgement/status furniture and exception-stack controls are not output rows. ConsoleRowCounter retains chunk checkpoints and a row count, counts newlines in appended pipe suffixes and allocates no per-line strings or newline offsets. It resets and reconstructs counts on rewind/replacement. Prefix identity/string comparisons remain part of update work; this is not a constant-time CPU claim.

Problems uses the same mergeProblems and openDiagnostic owners, with the complete message, visible severity and recorded path/line/column. Its count is the same merged diagnostic list. DebugDrawer moves physically with its executable body unchanged; its count sums breakpoints and the stack/variables passing the same paused-session identity guard. ErrorsDrawer retains ErrorExplorer and the actual exception fallback. The count includes every captured exception episode, matching ErrorExplorer’s complete recording list independently of the World cursor. Curated recordings can open their own ErrorExplorer without borrowing workspace stderr.

Dock toggle actions retain the existing Shell tool/open/pin fields. Registry Show Console/Problems/Debugger commands remain explicit open operations. The retired bottom divider path is removed; the project/runtime divider behavior is preserved. The old ProblemsPanel, root DebugDrawer and tools.css owners are physically replaced by Dock modules and styles. Active drawer/Console styles now belong to styles/dock.css, use frozen colors and at least 12 px text; the old tool strip/footer/JDK banner rules are removed.

Status summary names the current language status with a distinct glyph. StatusPopover shows the actual JDK version/error, language status and full reported reason, classpath mismatch, build system/diagnostic, capture budgets/watchdog, current capability/support diagnostics and notices. The existing mounted-surface stack owns Escape, focus and modal priority. Outside activation and Escape restore the summary. Configure JDK uses DialogFrame and the unchanged detectJdk action; its modal now joins the existing keyboard blocker list. Status metadata has no persistent banner. Shared command descriptions choose above-anchor placement when below-anchor space is insufficient.

`dock-owner-equivalence.json` extracts TypeScript AST initializers: operation owners remain byte-identical except removal of the two automatic height resets in acceptRaw. It also hashes the exact preserved Console JSX, Debug body and output builders. Backend/runtime, instrumentation, registry/matcher, camera, semantic goldens and provenance remain unchanged.
