The existing rounded text mask uses the actual focused cell; whole-array Focus still does not mask a fictitious filled envelope.

Focus optionally accounts for caption clearance while measuring **only the actual cell front face** for the unchanged 38–52% height and preferred 25–35% width bands and prescribed angles. Caption points use the bundled Inter 500 ink metrics about Troika's middle anchor. Generated metrics have a font SHA guard. Font-dependent code stays in the text renderer; layout/window geometry does not import font metrics.

The narrow Inspector uses 30% height during Focus and its previous 45% outside Focus; contents remain virtualized and reachable. Opening/resizing surfaces does not introduce a camera intent. Existing explicit-request deadlines and synchronous user-camera cancellation remain.

Three camera files are intentional, demonstrated exceptions to the protected-camera boundary: `CameraRig.tsx`, `focusFraming.ts`, and its test. All other camera files remain protected. Moving the index behind previous-row geometry, shrinking fonts/faces or relaxing those assertions was excluded.
