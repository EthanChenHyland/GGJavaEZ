## Current storage admission

`currentStorage` extracts only explicit storage IDs from the current normalized event. `SceneModel.cursorEvent.storageIds` is a presentation hint, separate from owner indexing and graph provenance. The planner requests a bounded frame row for an actual captured, still-live slot. Graphless declarations, assignments, input destinations, array-read destinations and reference bindings therefore remain inspectable without requiring Selection/Focus or camera guidance. It adds no semantic event, graph edge, value, canonical port or body size. Array/class/object IDs that do not denote a live frame row cannot create one.
