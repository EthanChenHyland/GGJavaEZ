# Recording-owned connector route cache

The recording compiler in `WorldSurface` owns one `ConnectorRouter`. Presentation planning supplies the ordered represented bodies and exact semantic ports. The router retains at most two geometry contexts and 256 immutable paths per context; eviction removes derived geometry only. It holds no runtime state, execution graph, trace, scene, captured values or provenance records.

Context identity includes each represented body's canonical ID, position and size, in order. Order remains significant because equal-distance obstacles use stable input ordering in the existing bounded visibility-grid search. Route identity includes exact source/destination coordinates, source/destination body geometry and departure direction. Coordinate-wrapper recreation reuses geometry; changed ports, represented bodies or dimensions invalidate it. No cache key derives from formatted Java names.

Face rectangles are prepared once per represented cut. Each uncached route prepares segment bounds once, then uses the existing face-clearance and exterior-corridor algorithm. The initial prepared-routing optimization preserved the algorithm's behavior, including its overly broad terminal exemption. A subsequent correctness change clips actual segments against represented face volumes and admits only the connected departure/arrival corridor within 0.14 units of the actual port row, toward the same side as that port. Wrong-side entry, row wandering and later re-entry are rejected. Exact canonical endpoints stay unchanged; exterior routing supplies the detour. Actual diagonal corner clearance is distinguished from bounding-box overlap. Geometry checks cover left/right ports, same-body references and intervening obstacles; full native picking and screenshot review remain required.

Unrelated Home/Focus camera intents no longer invalidate presentation planning by themselves. Cluster-travel intent remains an input because its actual member must be presented. Scene, selection, Focus target, Trace scope and semantic detail changes still replan normally.
