## Reference comparison and acceptance

`best.png` establishes runtime-first hierarchy, source as a subordinate wing, blue invocation geometry, purple heap, attached references and the integrated timeline. The final application shares that hierarchy while retaining real Monaco, project editing, debugger, source binding and canonical Console. The other five root concepts guide recursion descent, array cuboids, selected-face inspection, return history, exceptions and semantic zoom. References 06–11 protect consistent rectangular solids, measured faces, materials, lighting and topology.

Final original-size category review covers objects/constructors, populated collections, primitive/reference arrays, class statics, observed I/O, caught/uncaught exceptions, retained invocation history, partial recording, dense macro and all four requested sizes. Genuine top/side planes and extrusion remain visible in the final hero. No flat CSS perspective world, decorative city, excessive bloom or separate per-scene design system was introduced. Completed history stays neutral rather than globally glowing.

Focus fits the selected information face with modest side/top depth and at most two nearby observed neighbors. Selection alone does not move the camera. Free navigation overrides automation during playback; arbitrary scrubs update the same anchors in place. These behaviors are verified by interaction tests and native audit, not inferred from pixels. All recorded values remain in Inspector; distant bodies intentionally use bounded detail, and declared/unobserved array entries are not fabricated.

## Known visual limits

Narrow Source + Console + Inspector layouts leave less world area; Expand runtime and scroll remain deliberate affordances. Arbitrary long names/values can require search, Inspector or Focus. Historical off-screen context and quiet/clustered bodies are not missing semantic data. The authored older control example retains its legacy contextual readout; a Phase 5.5 small-layout audit should simplify that overlap. Complete branch/cell/field catalogs are intentionally not simultaneously labeled at macro distance. Remaining long-name and sustained GPU/text-memory profiling belong in the documented follow-up rather than a new Phase 6 feature.
