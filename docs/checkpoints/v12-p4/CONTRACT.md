## Memory gate

Before broader runtime implementation, the identical seeded Phase 3 paired probe reproduces 190,031 rich events, 67,849 values and 110,408 edges: 817.76 MiB / 2559.997 ms. Packed, prefix-compressed hash-trie Record storage reduces this to 353.18 MiB / 1965.529 ms. All four graph SHA-256 digests agree. Existing reference reducer, history and graph tests pass. Array facades, identities, event order and graph contracts are unchanged. Bounded heap attribution and further regression measurements are recorded separately; snapshot runs are not clean timing samples.

## Additive observation contracts

- Raw NDJSON remains version 1; `coverageVersion: 1` opts into expanded observations. Existing archives and legacy int-array numeric records retain their meaning.
- Longs use canonical decimal strings; old safe numeric longs still load. Float/double nonfinite values use `NaN`, `Infinity`, `-Infinity`; negative zero uses `-0.0`. Char is exactly one UTF-16 code unit, including a JSON-escaped surrogate. No numeric narrowing at the TS boundary.
- Arrays retain actual object identities. `elementType` is the Java component type; `length` is total length. `elements` is a bounded initial prefix of RawValues (legacy int numbers accepted). Nested arrays are actual child references. Reads/writes emit only after the original successful JVM opcode, carrying boxed typed values. Writes outside the initial prefix use sparse observed storage, never fill unknown cells or allocate proportional to an enormous length.
- `class_state` carries declaring owner, observed static fields and initialization `started`, `completed` or `observed`. `static` / `static_read` carry exact declaring owner/name/descriptor, actual value and bytecode origin. Class IDs are `jvm:class:<binary owner>`; static slot IDs include owner/name/descriptor. RuntimeClass storage is distinct from instances. `<clinit>` remains a real invocation with observed ordering; class observation does not invent initialization completion.
- `string_object` carries actual identity, bounded user text, total UTF-16 length and truncation. References point to that identity. Legacy inline Strings remain value summaries. Internal byte arrays, coder/hash and cache implementation fields are hidden.
- `library` carries actual object ID, runtime class, ownership and bounded semantic summary: `LIST`, `SET`, `MAP`, `QUEUE`, `DEQUE`, `BOXED` or `OPAQUE`; size; order; items or key/value entries; truncation/reason. Summaries are observations at boundaries, not continuous tracking. Exact verified bootstrap JDK classes only. The helper is a named `visualjava.observer` module; `java.util` opens target only that module, preserving application reflective access. User overrides, unknown layouts and unsafe access are opaque; no user iterator, equals, hashCode, comparator or toString is called by observation. Items preserve actual object IDs and nulls. Maximum 32 child references (16 map entries).
- `file_io` represents a successful observed operation (`open`, `read`, `write`, `close`), path when established, call ID and bounded preview/count where available. No invented path or giant file copy. Buffered resources require evidence from a successful Files factory; in-memory wrappers never become file endpoints. Arbitrary API internals remain opaque.
- Metadata is renderer independent: runtime/declared type, package, ownership `PROJECT`/`LIBRARY`/`JDK`/`SYNTHETIC`, synthetic/record/enum flags and components where observed. No XYZ, camera, material, glow or animation fields.

Semantic schema 2 is extended additively with `CLASS_OBSERVE`, `SET_STATIC`, `OBJECT_OBSERVE`, general array values and optional metadata. Existing event ordering and graph goldens for unchanged input remain exact. Static/collection observations extend graph storage/observation facts without inventing writers or causality. Reference values retain declared type in slots and actual runtime type in object metadata. A successful JVM store proves assignability; the reducer does not guess inheritance from names.

## IDE commands and filesystem changes

Canonical typed commands live outside React; menus/buttons/keybindings call the same operations. Context targets are explicit, including inactive tabs. Bulk close resolves dirty decisions before closing anything; cancellation preserves all tabs. Close Saved preserves dirty drafts. Copy Path uses project-relative POSIX paths. Filesystem rename is byte-preserving and distinct from JDT Rename Symbol.

Rename reconciliation preserves latest open and closed drafts, tab order, active path, desired workspace breakpoints, Explorer/navigation paths and launch cwd. Derived project/diagnostic/language state is invalidated/reconciled. Captured manifests, source IDs/hashes, graph and anchors are immutable. A workspace-side proven move binding resolves historical sources; mismatched current content is never highlighted as the captured program. Desired workspace breakpoints are distinct from recorded session breakpoints. Presentation projects acknowledgments only through receipt-backed bindings and effective-source SHA-256 equality; dirty/unproven/missing paths remain pending. Execution builds capture their source manifest under the same queue as file commands, retaining a private per-compilation snapshot instead of rereading a moved/edited workspace after releasing the build barrier. Portable filename rules are tested synthetically; native platform claims are limited to available macOS.

## Ownership

Lead owns contracts, memory storage, raw normalizer/provenance and integration/final validation. IDE worker owns canonical commands/path-change/source-binding modules, IdeWorkspace and bridge/JDT reconciliation. Java transformer worker owns original-opcode probes and verifier-focused tests. Library worker owns the five standalone safe observation/access helpers. Reducer worker owns shared value validation, runtime class/object/array reduction and trace validation. No worker commits or independently changes architecture. Every handoff lists files, decisions, tests and limits.
