# Product simplification — Milestone 11.5

Status: **completed lead audit and visual acceptance, 2026-09-30**. Compared baseline `dfa3091` with the Milestone 11.5 implementation. Final gates: 591 unit/integration tests across 62 files, 85 browser tests, build/typecheck and configured lint passed. Fresh-session JSON, screenshots and replay evidence are linked below.

## Comparison boundaries

Milestone 10 baseline is `aae90dba689014a421f67246d026f4f438bc8a71`; Milestone 11 is `636436b`; its later Focus fix is `dfa3091`. Keep those changes separate from the uncommitted 11.5 diff when reporting simplification totals.

Its prior screenshots are historical artifacts, not evidence for current arbitrary-project Focus.

Root has audited the post-V10 diff. Important finite adapters remain as compatibility paths, documented below.

## Visible controls: what was actually reduced

The concrete route-level reduction is that **normal `/` startup no longer exposes the curated Example dropdown or its Person/Recursion/Arrays/Control choices**. Those controls remain on `/examples`. The normal IDE still exposes Run/Debug or Stop, More actions, Explorer disclosure, project controls, runtime representation/guidance/flow/navigation controls, a contextual inspector/Focus control, timeline, conditional debugger controls, and bottom tool tabs.

No wholesale topbar/control-count reduction relative to `dfa3091` is established by the inspected 11.5 diff. The compact execution toolbar and disclosed Save/Build/JDK actions already existed. No new activity rail, File/View menu, or application command palette is implemented by this diff. Do not count these targets as complete.

### Modes and panel behavior

The current IDE keeps internal `code`/`visualize`/`debug` layout emphases and a separate `runtimeExpanded` presentation flag. There is no visible Code/Visualize/Debug mode chooser in the inspected header; Run and Debug drive the execution emphasis, while Focus remains a view treatment. This arrangement is inherited from the prior unified workflow, not a new 11.5 merge of four buttons.

Spatial/Classic/eligible Theater are still representation controls inside one runtime surface. Relevant/Current/All are still flow presentation filters. Guidance and Follow remain explanatory/navigation controls. These remain view/navigation controls within the shared execution workflow.

Classic remains an optional 2D SVG projection. [ClassicRuntime.tsx](../../../src/classic/ClassicRuntime.tsx) avoids constructing its entity graph while hidden, but mounts all projected entities/slots/references when visible, with no Spatial detail/archive budget. [viewport.ts](../../../src/classic/viewport.ts) uses finite Home/pan/zoom bounds. Its large-world DOM cost and overview framing remain optional representation debt, not a core Spatial acceptance block.

Bottom-panel disclosure, Console/Problems/Debugger/Error Explorer tabs, focus source drawer, contextual inspector and resize dividers remain. Conditional tool availability now avoids making an old recording's exception trace the current session's Error Explorer. Current process output is separate from retained old trace output. The status strip now suppresses routine ready project/language labels, shows actionable failures/classpath mismatch, and offers Retry Java for failure/unavailability; Capture limits is a disclosure rather than a permanent expanded warning. A top status strip and editor foot still exist; this does not establish a fully consolidated status bar or a new bottom-panel redesign.

Runtime remains mounted beside source after a project opens, including the idle trace; it expands with observed execution and can fill the workspace in Focus. Before project selection the explicit first-use surface takes the workspace. Spatial and High animation quality are defaults when corresponding preferences are absent. Expand runtime collapses ordinary Console on entry; pending stdin stays open, Error Explorer/other inspection stays visible, and the Console tab always reopens it. The latest Focus probe verified full-height inspection; final lead visual review passed for the captured states.

## Explorer: implemented versus still limited

[ProjectExplorer.tsx](../../../src/ide/ProjectExplorer.tsx) provides right-click, row ellipsis and Shift+F10/ContextMenu access to New Java Class, New File, New Folder, Rename, Delete, Reveal in editor and Refresh. Arrow keys traverse visible rows and expand/collapse; Enter opens files; F2 renames and Delete requests deletion. The older M10 per-row rename/delete icons were replaced by the M11 context-menu component before this working diff. Do not attribute that removal to 11.5.

The current diff improves menu traversal, dialog trapping, initial parent suggestions and dirty-file deletion. New Java Class still asks for a **project-relative path ending in `.java`**, not simply `Foo` in all contexts. Package boilerplate is generated only for a unique matching source root with valid package components; ambiguous roots yield no guessed package. The feature is not Java package/class-aware rename/refactoring: Rename updates filesystem paths/open tabs, not declarations or references.

Retained permanent Explorer controls include New File/New Folder/Refresh, project select, Import folder (copy), New project and Reveal active file. There is no implemented dedicated Collapse All control or tree Home/End behavior in the inspected code; Home/End are menu keys. The overlay Explorer remains the narrow-viewport presentation.

## State integrity, known limits and final lead gates

ExecutionSession owns execution truth. Retained visualization records its originating session ID; snapshots, selection, pane widths and Focus are presentation state. Handoff retains the old world's cursor/presentation and labels it Previous recording; a new session owns Console/source state. Maven completion/failure and retained replay checks passed.

Known limits: finite Visualize compatibility adapters remain after the post-V10 audit; Classic's finite overview/full SVG population is optional representation debt; filesystem rename is not Java refactoring; this diff does not add an application command palette, activity rail or File/View menus. Native Windows/Linux runs were not performed, with synthetic shortcut contracts verified. Cache retention bounds directory count rather than bytes; one active index can still grow.

**Final lead gates passed:** 591 unit/integration tests, 85 browser tests, build/typecheck, lint and final screenshot/motion review. The companion coverage matrix records bounded observations and unsupported constructs; native Windows/Linux runs and optional Classic scale are explicitly outside the measured acceptance.
