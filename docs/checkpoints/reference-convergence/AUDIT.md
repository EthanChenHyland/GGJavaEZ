## Basis of comparison

The reference stills establish the expected product composition, material response, and interaction intent. Apparent field values, object IDs, call order, and program contents in generated stills carry no semantic authority. Empty space arising from a smaller recorded program is legitimate. The use of that space, the relative prominence of observed objects, and the readability of the resulting runtime remain reviewable.

The original suite contains **18 image files, representing 12 distinct designs**. The root files and tracked twins were checked byte for byte. The 12 distinct bitmaps were inspected at their original dimensions. The five untracked root references remain untracked. Where a board contains multiple panels, each is an interaction/composition study, and its crop is treated as such.

## Functional smoke and setup defect

The build, production and reference TypeScript checks, lint, and three targeted measurement/reference-integrity tests passed. `node scripts/reference/measure-build.mjs` reproduced the qualified **71,873-byte** main entry. The earlier full functional counts remain historical qualification, with this audit independently driving focused real-JVM states.

**JDK 17 trial.** An ordinary tiny Java program can compile and exit 0 while the observer helper compilation fails on `Thread.threadId()` and `PrintStream.charset()`. The app displays Completed and an adjacent instrumentation preparation diagnostic while the timeline remains at 0/0. JDT also returns 503 on 17. The README lists a complete JDK and recommends 21+ while explicitly requiring 21+ for the optional language service. On this path the observed recorder needs a newer JDK too. Treat this as a functional setup failure even though the application is still usable as an editor. The audit used the already provisioned JDK 26.0.2.1 and pinned JDT installation for the subsequent visual runs. See `jdk17-matrix.log` and the original Playwright error contexts in `matrix-playwright/`.

The browser matrix executed **20/20 selected cases** on JDK 26, including all sixteen named comparable states at 1728×1117 and the other four responsive sizes for Hero. Those cases produced 36 fresh PNGs, including 16 native-size retakes, along with paired comparisons and differences. Playwright recorded zero case failures and zero retries. The count-enforcing matrix reporter correctly flagged the filtered run as incomplete at 20 of 80. This checkpoint uses that scoped evidence alongside independent actual-JVM supplemental runs. It does not claim the full reference gate.

The ASCII-locale trial delivered the exact Unicode input request but captured `?` for the emoji in JVM stdout. JDK 26 reported US-ASCII for native and standard-stream encodings under this shell’s inherited locale. Restarting the same app with `LC_ALL=en_US.UTF-8` changed all three stream encodings to UTF-8 and the same Console test passed, including blank input, delayed acknowledgment, exact emoji and post-exit guard. See `supplement.log` and `utf8.log`. The failed initial class-state diagnostic used an incorrect terminal expectation for the fixture’s deliberate final uncaught exception. The corrected probe uses the actual failure endpoint and captures the real throw, unwind and catch. A supplemental I/O test initially toggled the already-open waiting-Console closed during UI hydration. Waiting for the frontend liveness badge and using the existing open drawer recovered the native input/consumption sequence. These setup and audit-driver outcomes are retained in the logs.

## Reproduction

Run in an isolated checkout of the audited revision. The existing matrix writes generated captures under its checkpoint directories. Use an isolated bridge workspace, the existing pinned JDT installation, a complete compatible JDK, and the native UTF-8 locale on macOS. Only one runner should own the bridge.

```sh
npm run dev -- --port 5173 --strictPort
npx playwright test --config playwright.reference.config.ts --grep '1728x1117|Runtime hero view'
npx playwright test e2e/reference/collection-presentation.spec.ts e2e/reference/connector-hover.spec.ts e2e/reference/debug-drawer.spec.ts e2e/reference/follow-path.spec.ts e2e/reference/header-badges.spec.ts e2e/reference/recursive-camera.spec.ts --grep '1440x900' --grep-invert 'reduced'
```

The two audit-only local Playwright drivers are preserved under `audit-tools/` in the ignored evidence bundle. Place them in `e2e/reference/` of the isolated checkout to run them. They cover the smaller Person, selected native gestures, GPU quality pair, motion, and recurring lifecycle memory. The exact reviewed Java source for Person is preserved in its session JSON and in the local driver. The existing test, rendering, and JVM sources are unmodified.
