# Visual scorecard

**Independent audit baseline · PARTIALLY CONVERGED · 37/100.** The merged app has the expected shell topology, actual three-dimensional runtime geometry, semantic roles, and working navigation. The current product still reads as a set of brightly outlined information panels. Reference art uses optical depth, floor contact, a strong featured subject and much quieter causal context.

Each 0–5 dimension contributes equally to a state mean. The 19 state means contribute equally to the final 0–100 score, rounded to a whole number. Reference fidelity scores the perceptual impression of the whole state independently. Interaction state scores what the visual state communicates. Functional gate success alone adds no points.

## Typography and geometry

- Native Hero source starts at (10, 94) and is 418×527, close to the reference silhouette. The bright, opaque rectangular editor, file controls, gutter and footer flatten the source edge. Long recorded lines truncate at the right edge. In the native Person Home, the actual highlighted write is at line 18 close to the bottom of the panel. Project and run configuration receipts remain useful.
- Hero headings are approximately 36 CSS px at 1672×941 by the renderer’s font probe. Their tracking and position above the apparent near-common baseline draw attention before the mutation. Large runtime titles coexist with aggressively cropped chip values, repeated type/class text and rows lost at distance. At 760×900 the roughly 13 px live frame titles survive with multiple row names suppressed, leaving value chips without labels.
- The visual reference prioritizes method or class name, then ID, then aligned field/type/value columns. App method titles use owner plus full signature and often wrap. Fields/chips can consume most contrast while exact values such as the Person name get middle-elided. Both quality tiers show this, because changing tier preserves the same factual face presentation.
- Row bands and stack heights reserve for data over time. This supports spatial identity but leaves tall empty portions of recursion and collection faces. Authentic indexed cubes and amber indices make the five-cell array the closest matched geometry. A smaller active frame is semantically correct for ordinary Java with one live invocation.
- The Time Dock box aligns with R1 at native resolution (x 15, y 818, height 100 CSS px). The presentation delta lives in the opaque fill, raw-event ruler density, generic JVM labels, and truncated milestone names. The Inspector keeps exact details accessible but physically spends its first screen on actions, source and provenance. The two-field Person exposes only name in the initial field area.

## Connectors, material and lighting

Current/past bindings and real selected endpoints are supported. A fresh hover test selects neither entity nor camera; Follow Path exercises an actual drawable Flow. The failure is visual priority. Native Hero draws 23 curves including two bundle curves. The smaller Person Home still draws 12. Paths leave correct chip edges but take long detours and overlap, cross projected silhouettes or converge between similarly luminous lines. Stack call links, heap bindings and source-to-target flows need visibly distinct hierarchy. Exceptions are the strongest example of red emission exceeding the useful path bounds. Array writes should draw only evidenced data movement; a generated swap arc is no reason to animate an invented write.

## Independent review

A read-only second reviewer separately examined the fresh source-bound originals, verified all 36 image hashes against their capture records and reopened the primary references. Their first priorities were causal connector order, depth/material/floor response and readable framing. They rated the five-cell array strongest and noted the 760 px glyph-loss case, cropped recursive callers and weak Focus isolation. Their 0–10 impressions were directional input. This scorecard uses the stated nine-dimension scale and includes the ordinary, smaller Person workload and supporting states.
